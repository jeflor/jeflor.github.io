# Jeff Florentino Portfolio

Personal portfolio for Jeff Florentino, focused on AI automation, integrations, systems, and AI-assisted development.

## GitHub Pages

This is a static site with no build step.

1. Open the repository's **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. GitHub Pages will publish the site at:

https://jeflor.github.io/

## Updating the site

- Main page: `index.html`
- Styling: `styles.css`
- Small interactions: `script.js`

The site intentionally avoids presenting Jeff as a conventional senior software engineer. It positions his actual strength: business systems, automation, integrations, AI workflows, and the ability to use modern development tools to solve operational problems.
